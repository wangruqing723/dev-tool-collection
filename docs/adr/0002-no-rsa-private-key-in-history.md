# RSA 私钥不写入密钥历史

SM4 命令把用过的密钥明文存进 Raycast 的 `LocalStorage`，AES 将沿用这一便利。但 Raycast 的 `LocalStorage` 不是加密存储（只有 preferences 中标记为 `password` 类型的项才进钥匙串），因此决定：对称密钥（SM4、AES）可进密钥历史，**RSA 私钥一律不进**，历史中只允许出现公钥或密钥文件路径。

理由是二者的暴露代价不对等。对称密钥多为一次性会话密钥，泄露影响有限；RSA 私钥是长期凭据，且用户磁盘上本就有正本，再复制一份明文进 `LocalStorage` 只是白白增加一处暴露面，没有换来任何新能力。

## Consequences

RSA 命令每次使用都需重新粘贴 PEM 或重选密钥文件，比 AES 麻烦一步。这是刻意的取舍，不是尚未实现的功能——请勿「顺手补上」RSA 私钥历史。
